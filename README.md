# myKaggle

A personal workspace for building machine-learning knowledge through classic Kaggle
competitions. Each competition lives in its own top-level folder and follows the same
layout, so the workflow is consistent from one project to the next.

## Folder structure

```
myKaggle/
├── .venv/                  # shared Python virtual environment (local only, do not commit)
├── Titanic/                # Kaggle: Titanic - Machine Learning from Disaster
│   ├── data/               # raw competition data
│   │   ├── train.csv           # 891 rows, 12 columns, includes the target `Survived`
│   │   ├── test.csv            # 418 rows, same features, no target
│   │   └── gender_submission.csv  # Kaggle's reference submission (baseline to beat)
│   ├── src/                # source code
│   │   └── logistic_regression.py
│   └── output/             # generated predictions
│       └── submission.csv
└── README.md
```

### Per-project convention

Every competition folder uses the same three subfolders:

| Folder    | Purpose                                                        |
| --------- | -------------------------------------------------------------- |
| `data/`   | Raw files as downloaded from Kaggle. Never edited by hand.       |
| `src/`    | Source code. One script per modelling approach.                  |
| `output/` | Anything generated by code: submissions, plots, saved models.    |

## Environment

Python 3.12 via a shared virtual environment at the repo root.

```bash
# create the environment (only needed once)
python3.12 -m venv .venv

# install dependencies
./.venv/bin/python -m pip install pandas scikit-learn
```

Installed versions: `pandas 3.0.6`, `scikit-learn 1.9.1`.

## Running a project

```bash
./.venv/bin/python Titanic/src/logistic_regression.py
```

### Titanic

Predict whether a passenger survived. Features are `Pclass`, `Sex`, `Age`, `SibSp`,
`Parch`, `Fare` (plus derived `FamilySize` / `IsAlone`) and one-hot `Embarked`.

The script reports cross-validation accuracy, fits on the full training set, prints the
learned `intercept` and `coefficients`, then writes `output/submission.csv`.
